# Getting help

| You want to | Go to |
|---|---|
| Ask how something works, share what you built | [Discussions](https://github.com/nirholas/three.ws/discussions) |
| Chat in real time | [Telegram](https://t.me/three_ws_community) |
| Report a bug | [Bug report](https://github.com/nirholas/three.ws/issues/new?template=bug_report.yml) |
| Propose a feature | [Feature request](https://github.com/nirholas/three.ws/issues/new?template=feature_request.yml) |
| Report a vulnerability | [SECURITY.md](.github/SECURITY.md), never a public issue |
| Contribute code | [First contribution guide](docs/first-contribution.md) |

Docs live at [three.ws/docs](https://three.ws/docs) and the long-form reference is [docs/reference.md](docs/reference.md).
