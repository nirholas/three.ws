## MoMask on model-text2motion

MoMask has no in-house production run yet; the weights are staged under `gs://three-ws-model-weights/momask/`. Owner steps, in order:

1. Deploy a revision that serves the MoMask backend: `gcloud builds submit --config workers/model-text2motion/cloudbuild.yaml . --substitutions=SHORT_SHA=manual$(date +%s)` (owner-gated; see the worker README).
2. Run the benchmark against the new revision URL:
   `WORKER_KEY=$(gcloud secrets versions access latest --secret=avatar-reconstruction-key --project aerial-vehicle-466722-p5) node workers/model-text2motion/scripts/benchmark-momask.mjs --url <worker url> --models momask,mdm`
3. The script exits 1 if any quaternion track is not unit norm and prints frames, latency (cold and warm median) per prompt. Paste the table into the worker README to replace the "has not yet had an in-house production run" paragraph.
