# Solana Memo Media MCP

`@three-ws/solana-memo-media-mcp` turns embedded image data URIs in Solana SPL Memo instructions into safe inline MCP images. It removes the copy-paste path through a data-URI converter while retaining the transaction signature, immutable digest, and validation result needed for provenance.

Install it with `claude mcp add solana-memo-media -- npx -y @three-ws/solana-memo-media-mcp`. See the package [README](../packages/solana-memo-media-mcp/README.md) for every tool, parameter, safety limit, and RPC configuration option.
