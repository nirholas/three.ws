## Discovery layer on every mirror

Each mirror README also gets the shared growth block (star and share links, agent entry points, contributors wall, star history) from `scripts/lib/repo-growth-kit.mjs`, applied during `decorateReadme`. A sync therefore reproduces it instead of erasing it. See [GitHub growth kit](./github-growth.md).
