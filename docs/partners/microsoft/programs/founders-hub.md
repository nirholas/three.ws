## Current name and form

Microsoft's documentation now calls the program **Microsoft for Startups**; the Founders Hub name no longer appears on the application page. The application starts at [microsoft.com/startups](https://www.microsoft.com/en-us/startups) with **Get started now**, signs in with a Microsoft account, and asks for an investor referral code. There are two paths:

| Path | What happens | Starter Azure sponsorship |
|---|---|---|
| With a 10-character investor referral code | Contact details, email and phone verification, a business information form, then Azure account setup. Reviewed "within three business days". | $1,000 immediately; approved startups unlock "up to $150,000" |
| Without a code (**Continue without a code**) | LinkedIn identity check, then straight to Azure account setup, no long form. | $200 immediately; more "based on factors such as business verification, service adoption, usage patterns, and overall program eligibility" |

Recommendation: ask any investor or accelerator three.ws works with whether they are in Microsoft's Investor Network before applying. Microsoft does not publish the list, and the code path is worth five times the starter amount.

## Before you apply (from Microsoft's checklist)

- A **personal** Microsoft account "with no prior Azure account". Work, school and company-domain addresses "aren't accepted" at sign-in, so the owner uses a personal address here and the company address only as the contact email.
- Phone number and time zone.
- Registered startup name and address that "must match your legal documents"; a mismatch "can cause business verification to fail".
- A payment card. The sponsorship subscription "automatically converts to pay-as-you-go" when the sponsorship is used up or expires, so set a budget alert on day one.
