1. IN ONE LINE

three.ws is an open-source platform for 3D AI agents: it turns a text prompt into a rigged,
animation-ready 3D character you can embed anywhere.

Tagline: Give your AI a body.


2. THE SHORT VERSION (ABOUT 50 WORDS)

three.ws is an open-source platform for 3D AI agents. It turns a text prompt into a rigged,
animation-ready 3D character, gives that character an on-chain identity and a payment rail, and
embeds it into any website or assistant with a single tag. The free 3D generation lane requires no
account, no API key, and no payment.


3. THE FULL VERSION

three.ws is an open-source platform that gives AI a body. It turns a text prompt, up to six photos,
or a sketch into a textured, rigged, animation-ready 3D character; gives that character a mind, a
voice, an on-chain identity, and a payment rail; and embeds the result into any website, app, or AI
assistant with a single tag.

Every avatar is a full agent, not a static model. The runtime wraps the character around an LLM
brain that listens, speaks with real-time lip-sync, gestures, remembers, and expresses emotion
through the model's face and posture, live in the browser with nothing to install. Any humanoid rig
works: the animation system retargets a shared motion library onto whatever skeleton a model
arrives with.

Agents on three.ws are economic actors. Each one can hold an on-chain identity on Solana, the
platform's home chain, carry a wallet and a human-readable name, and pay or get paid by other
agents per API call over x402, the HTTP 402 payment standard. The platform coin, $THREE, lives on
Solana.

Distribution is the point. A finished agent ships as the <agent-3d> web component that drops into
any page, and every generation and animation tool is reachable by AI assistants over MCP (Model
Context Protocol). The goal: as the internet gains an agent-native, three-dimensional layer,
three.ws is the infrastructure it runs on.

6. WHAT THE PLATFORM DOES (THE FIVE CORE FUNCTIONS)

1. Generate. Forge (three.ws/forge) turns a text prompt, up to six photos, or a sketch into a
   textured, downloadable GLB. Free draft tier with no account. Auto-rigging, restyling,
   retexturing, and remeshing in the same flow. Prompt-to-avatar produces a rigged, animatable
   character in one step. Paid tiers add high-quality generation (200k polygons plus PBR) and
   game-ready Unity/Unreal export.

2. Render. glTF 2.0 / GLB in WebGL 2.0 on three.js r184, with Draco, KTX2, and Meshopt
   decompression, Khronos-spec validation, HDR environments, PBR, skinned animation, and morph
   targets. Zero server-side processing on the render path.

3. Embody. An LLM brain with a tool loop of up to eight iterations per turn, built-in tools
   (wave, lookAt, play_clip, setExpression, speak, remember), weighted emotion blending, talk mode
   with ARKit-52 audio-driven lip-sync, browser speech-to-text (Web Speech, Moonshine, Whisper),
   and production voice. Memory, skills, and persona.

4. Register. On-chain identity as an ERC-8004 token on any EVM chain or a Metaplex Core asset on
   Solana: stable agent ID, owner wallet, delegated signer, signed action log, and a reputation
   score that cannot be forged.

5. Embed. The <agent-3d> web component (one script tag, no framework), five widget types
   (turntable, animation gallery, talking agent, passport card, hotspot tour), Widget Studio,
   Open Graph and oEmbed previews, versioned CDN bundles at
   https://three.ws/agent-3d/latest/agent-3d.js.

9. PAYMENTS: X402 AND THE AGENT ECONOMY

x402 is the HTTP 402 payment standard: a client calls an endpoint, receives a price challenge,
pays per call in stablecoin, and gets the result. three.ws runs it as follows.

  Solana (primary) ....... USDC through the platform's own self-hosted facilitator
  Base ................... USDC through a facilitator, with Permit2 gas sponsoring
  BSC .................... direct-scheme leg
  $THREE ................. optional accept entry on endpoints

  Pay-by-name resolves @username, *.sol names, or raw addresses to a recipient.
  Discovery: https://three.ws/.well-known/x402.json and https://three.ws/x402
  Listed on x402scan.
  Snapshot (2026-08-25): 4,519 priced endpoints, 1,000,000+ individually priced datapoints at
  $0.0005 each, 110,416 on-chain settlements through the self-hosted facilitator plus 803,483
  payment verifications.
