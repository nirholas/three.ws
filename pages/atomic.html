      01

      4 known fields

      Priority fee (bits 0-1, 8 bytes), compute unit limit (bit 2, 4 bytes), loaded accounts data size (bit 3, 4 bytes), and requested heap size (bit 4, 4 bytes).

      02

      Sanitization aware

      The priority fee bits must both be set or both cleared. Atomic flags a mask where only one is set as a partial, invalid encoding.

      03

      Reserved bits

      Bits 5-31 are reserved. Atomic calls out any transaction that sets one, since a future SIMD may assign it a meaning this decoder does not yet know.

          01

          Caps, not hopes

          On V1, a Compute Budget instruction scan sees nothing. The real caps live in transactionConfig, and this view reads them from there.

          02

          Duplicate check

          SIMD-0385 makes a duplicate static account a sanitization failure. This view decodes the wire account list and flags one if present.

          03

          Zero means zero

          An unset V1 compute or data limit resolves to zero, not a legacy default. A sponsor relying on the old default would be wrong to assume otherwise.
