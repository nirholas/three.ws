Developer plans

Quotas that are enforced.

Every plan ships with a monthly call quota, a per-minute burst ceiling and a concurrency ceiling, and the API holds you to all three. You never find out from an invoice: a 429 carries Retry-After, a 402 names the plan above yours, and every response tells you where you stand.

Over the burst or concurrency ceiling: 429

HTTP/1.1 429 Too Many Requests
retry-after: 12

{ "error": "rate_limited",
  "plan": "free",
  "upgrade_url": "/developers" }

Back off for Retry-After seconds. The limiter is a sliding window, so a steady client never sees one.

Out of calls for the period: 402

HTTP/1.1 402 Payment Required

{ "error": "quota_exceeded",
  "plan": "free",
  "used": …, "limit": …,
  "reset_at": "2026-11-09T00:00:00.000Z",
  "next_plan": { "id": "builder", "included_calls": …, "price_usd": … },
  "upgrade_url": "/developers",
  "manage_url": "/dashboard/developers#plan" }

The refused call is not counted. Upgrade from the dashboard and the next call goes through.
