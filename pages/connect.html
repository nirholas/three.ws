One URL. Your AI gets three.ws.

Add three.ws to Claude, ChatGPT, Cursor, VS Code or Claude Code and your assistant can generate 3D models and avatars, run your agents, read their wallets and pay for services over x402. Sign in once in your browser: there is no API key to copy. Every tool is listed in the MCP tool catalog.

Works on claude.ai and the Claude desktop app, on every plan. Free accounts can add one custom connector. On Team and Enterprise, only owners can add one.

Open Claude with the URL filled in
  1. Click the button above, check the name and URL, then click Add. Adding it by hand instead: Customize → Connectors (Settings → Connectors on some accounts), Add custom connector, paste the URL.
  2. Click Connect and sign in to three.ws. Read the permissions before you approve.
  3. In a chat, open the + menu, then Connectors, and switch three.ws on for that conversation.

Steps follow Claude's own guide. Its menus move: if these drift, tell us.

ChatGPT adds custom MCP servers through Developer mode, on the plans where OpenAI offers it. There is no pre-filled link, so copy the URL first.

  1. In Settings → Apps & Connectors → Advanced settings, turn on Developer mode.
  2. Back in Apps & Connectors, click Create. Name it three.ws, paste the URL, choose OAuth, and create it.
  3. Sign in to three.ws when ChatGPT asks, and approve the permissions.
  4. In a new chat, open the + menu, choose Developer mode, and tick three.ws.

Steps follow OpenAI's developer mode guide. Its labels change often: if these drift, tell us.

Grok Bot adds custom MCP servers as connectors. There is no pre-filled link: enter these three settings. They follow the server you picked in step 1.

Transport Streamable HTTP
Server URL https://three.ws/api/mcp
Authentication OAuth
OAuth URL
  1. In Grok Bot, open the connectors settings and add a custom MCP connector.
  2. Set the transport to Streamable HTTP, paste the URL above, and choose the authentication shown above. The free servers need none. Every other server uses OAuth: sign in to three.ws when Grok Bot asks. On the Grok server, use the OAuth URL instead to add your agents.
  3. Start a task and ask for a 3D model or an avatar. Grok Bot calls the three.ws tools on your behalf.

Use the public https://three.ws URL only. A localhost or private-network URL never works, because Grok Bot connects from xAI's cloud, not from your machine.

Grok Bot shares one network address with other hosted agents. For your own generation allowance, generate a private connector URL below. The full walkthrough is on the Grok page.

One command adds the server. The first time a tool needs your account, Claude Code opens three.ws sign-in in your browser.

Terminal
claude mcp add --transport http three-ws-main https://three.ws/api/mcp
  1. Run the command. Add --scope project to share it with your team through .mcp.json.
  2. In Claude Code, type /mcp, pick the server you just added and choose Authenticate.

IBM Bob reads MCP servers from .bob/mcp.json in your project, or ~/.bob/settings/mcp.json for every workspace. Pick 3D Studio (free) above to connect with no sign-in; a server that needs sign-in runs Bob's built-in OAuth flow on first connect.

Add it to .bob/mcp.json
{
  "mcpServers": {
    "three-ws-main": { "type": "streamable-http", "url": "https://three.ws/api/mcp" }
  }
}
  1. In the Bob panel, open Settings → MCP and click Edit Project MCP (or Edit Global MCP), paste the entry, and save.
  2. Using Bob Shell? It reads the same files but names the URL key httpURL, so rename url to httpURL. Or let the CLI write it: npx three-ws setup --clients bob.

Config format from IBM Bob's MCP docs.

3

Worth knowing

You never copy a key

Signing in gives your client its own token for your three.ws account, with the permissions you approved on the consent screen. Tools act on the agents and wallets of the account you sign in with.

Revoke it any time

Every client you connect appears under Dashboard → Settings → Connected apps. Revoking one stops that client within an hour, when its current access token expires. Your agents and balances are untouched.

Every tool is labelled

Each tool declares whether it only reads, writes, or does something irreversible, so your client knows what to ask you about. The tool catalog has a ready-made trust policy to paste in.

Try it without an account

The 3D Studio (free) server needs no sign-in: text to 3D, image to 3D and rigged avatars. Pick it above and connect in seconds.
