Agent memory

Your agents can remember what you tell them and write down skills they work out. Everything they keep is listed here, and every line can be edited or deleted. Nothing leaves your account, and nothing is shared when an agent is sold. How it works

Learning

Control whether your agents save new memories and draft skills from what they do.

About you

A short profile every one of your agents reads before it answers. Agents add to it as they learn; edit anything that is wrong.

Saved memories

Facts, preferences and procedures your agents chose to keep. Deleting one removes it from every future prompt.

Learned skills

Skills an agent drafted after a run that used several tools. A draft stays off until you read it and turn it on.
