Integration · Basecamp

Make 3D models without leaving the Basecamp chat.

Add the three.ws chatbot to your Basecamp account, then type !threews and a description in any Campfire or Ping. A textured 3D model comes back in the same room in a minute or two, with a picture of it, a 3D viewer, a link to place it in your space with AR, and a GLB file ready for Blender, Unity, Unreal or a website.

Create your command URL Setup takes two minutes

Free with a three.ws account. Models are made on the free Forge lane and saved, unlisted, to the account that created the command URL.

Set it up

You need a free three.ws account and someone who is an admin of your Basecamp account. One chatbot works in every Campfire and Ping in that account.

  1. 1

    Create a command URL on three.ws

    Sign in (or create an account), open Settings, Basecamp chatbot, give it a name such as the Basecamp account it is for, and choose Create command URL.

    Copy the URL straight away. It is shown once, because it works like a password: anyone who has it can make models on your account.

  2. 2

    Add the chatbot in Basecamp

    In Basecamp, open any project's Campfire. Open the ••• menu at the top of the Campfire and choose Configure chatbots, then Add a new chatbot.

    Name it threews (that is the word people type after the !), paste the command URL into Command URL, and save. Only Basecamp admins and owners see Configure chatbots.

  3. 3

    Ask for a model

    In any Campfire or Ping, type !threews and describe what you want, for example !threews a brass desk lamp with a green glass shade.

    The chatbot answers at once, then posts the finished model in the same room and mentions you. Everyone in the room can open it in 3D, view it in AR or download the GLB.

Commands

!threews <description>
Makes a textured 3D model of the description on the standard quality setting. Descriptions can be 3 to 1,000 characters. A short, concrete object works best: what it is, what it is made of, its colours and style.
!threews <description> --draft
A quicker, lighter model for trying ideas.
!threews <description> --high
More detail and better textures. It takes longer.
!threews help
Shows these commands in the room.

What it can see and do

  • Only the command line. Basecamp sends three.ws the text after !threews, the name of the person who typed it, and a reply address for that one room. The chatbot never reads other messages, files, to-dos or people in your Basecamp account, and it has no Basecamp login.
  • It only posts back to Basecamp. Replies go to the room the command came from, through the reply address Basecamp provided, and only to Basecamp's own servers.
  • Models belong to you. Each model is saved, unlisted, to the three.ws account that created the command URL: it is owned by that account and not listed publicly. Anyone with the links in the room can open it.
  • The command URL is stored as a hash. three.ws keeps only a fingerprint of it, never the URL itself, and records how many commands it has served, when it was last used and which Basecamp account used it.

Revoke, limits and cost

  • Revoke any time. In Settings, Basecamp chatbot, choose Revoke. The chatbot stops making models at once and tells anyone who tries that its URL was revoked. Remove it from Configure chatbots in Basecamp too.
  • Limits. Each command URL accepts 20 models every 10 minutes, and an account can have 10 active command URLs. The same request repeated within a minute is recognised and made once.
  • Cost. Free. Models use the free Forge lane on three.ws servers; you do not need a paid plan or an API key.

Troubleshooting

Nothing happens when I type !threews

Check that the chatbot is named exactly threews in Configure chatbots, and that the command starts with !threews followed by a space. Basecamp only sends the command if the name matches.

The reply says "This three.ws chatbot URL is not recognized"

The URL was mistyped or cut off when it was pasted. Create a new one in Settings and paste it into the chatbot's Command URL in Basecamp.

The reply says the chatbot URL was revoked

Its command URL was revoked on three.ws. The account owner can create a new URL and update the chatbot in Basecamp.

It said it was making a model, but nothing came back

Most models arrive within two minutes; high quality models and busy periods can take longer. If generation fails, the chatbot posts that it failed and why. If neither arrives within 15 minutes, try again with --draft. If it keeps happening, email support@three.ws with the time and the description you typed.

It says Basecamp is sending more models than it can make

A command URL accepts 20 models every 10 minutes, shared by everyone in the Basecamp account. Wait a few minutes and ask again.

Can I use it in a Ping?

Yes. The chatbot works in Campfires and in Pings (one-to-one and group). Basecamp keeps a Ping's reply address for 24 hours, which is far longer than a model takes.
