Three Microsoft open-source projects, each doing its real job inside three.ws right now. Nothing here is a recording.

Microsoft Research · MIT

TRELLIS image-to-3D

Photos people turned into 3D models on the three.ws GPU fleet, newest first, from the public community feed. Each card is labelled with the model that made it. Open any one in the viewer.

Try TRELLIS.2 in the Forge
Source: microsoft/TRELLIS.2 and microsoft/TRELLIS Browse the full community gallery
ONNX Runtime Web · MIT

Speech to text on this device

Press, speak a sentence, and a speech model running in ONNX Runtime Web inside this tab writes it down. The same engine lets three.ws agents listen.

The first press downloads the model once. After that it loads from your browser cache.

Your words appear here.

Audio never leaves this device. This demo has no server fallback: the page downloads the model files, then transcribes in the tab and uploads nothing. Open your browser's network tab while you speak to check.

Model: Moonshine base (MIT). Runtime: microsoft/onnxruntime
