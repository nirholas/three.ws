Install

One URL, https://three.ws/api/mcp-grok, over Streamable HTTP. Searching the catalog needs no sign-in. Making a model needs a free account, so every value below adds ?auth=oauth to sign in, which also adds your agents.

In the Grok Bot desktop app

  1. Open Connect apps and choose Add a custom connector.
  2. Name it three-ws-grok, set Type to Remote HTTPS, and paste the server URL below.
  3. Press Add plugin, then approve three.ws sign-in once with your free account.
https://three.ws/api/mcp-grok?auth=oauth

Or let Grok Bot add it

Grok Bot has no install link, so this tab gives the exact values to paste. Steps from xAI's Grok Bot docs.

Every Grok user can add a custom connector on grok.com, and it takes any public MCP URL, which is exactly what this is.

  1. On grok.com, open Connectors and add a custom connector.
  2. Paste the URL below, choose OAuth, and approve three.ws sign-in with your free account.
  3. Ask Grok for a 3D model in any chat. It answers with a viewer link and a GLB.
https://three.ws/api/mcp-grok?auth=oauth

grok.com documents no install link for connectors, so this tab ships the URL only. On Grok Business and Enterprise, a team admin provisions the connector first.

Grok Build is xAI's coding agent for the terminal. One command adds the server; the plugin adds 3D skills, commands and an agent on top.

Add the server
grok mcp add --transport http three-ws-grok "https://three.ws/api/mcp-grok?auth=oauth"
  1. Install Grok Build: curl -fsSL https://x.ai/cli/install.sh | bash, then grok --version.
  2. Run the command above. Add --scope project to share it with a repository instead of keeping it to yourself.
  3. Run grok mcp doctor to check the connection, or type /mcps inside grok to see three-ws-grok connected.

The xAI Responses API connects remote MCP servers for you: pass the URL as a tool and Grok calls it server side. Making a model needs a free three.ws account, so set XAI_API_KEY and a three.ws key from API keys as THREE_WS_API_KEY, then run.

curl
curl https://api.x.ai/v1/responses \
  -H "Authorization: Bearer $XAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "grok-4.7",
    "input": [{"role": "user", "content": "Make a 3D model of a lunar lander and give me the viewer link."}],
    "tools": [{
      "type": "mcp",
      "server_url": "https://three.ws/api/mcp-grok",
      "server_label": "three-ws-grok",
      "authorization": "'"${THREE_WS_API_KEY}"'"
    }]
  }'
Python (xai-sdk)
import os
from xai_sdk import Client
from xai_sdk.chat import user
from xai_sdk.tools import mcp

client = Client(api_key=os.environ["XAI_API_KEY"])
chat = client.chat.create(
    model="grok-4.7",
    tools=[
        mcp(
            server_url="https://three.ws/api/mcp-grok",
            server_label="three-ws-grok",
            extra_headers={"Authorization": f"Bearer {os.environ['THREE_WS_API_KEY']}"},
        )
    ],
)
chat.append(user("Make a 3D model of a lunar lander and give me the viewer link."))
print(chat.sample().content)

Let three.ws wake your Grok Bot

A Grok Bot routine can start from a webhook. Point a three.ws webhook at it and Grok Bot gets to work the moment something happens on your account: an agent run finishes, an automation fires, a message arrives, an approval is waiting, a model is forged. The event's JSON reaches the run as context.

  1. In Grok Bot, create a routine with a webhook trigger and an instruction, for example: "Read the three.ws event in the body. If it is approval.needed, summarize what the agent wants to do and message me." Grok gives you a URL and a key.
  2. On Developers, Webhooks, create a webhook with that URL, pick the events, and paste the key into Bearer token. It is stored encrypted and never shown again.
  3. Press Send test. Every delivery carries Authorization: Bearer <key> plus the usual signature headers, retries with backoff, and shows up in the delivery log.

Grok Bot allows up to 200 runs an hour per routine, so pick the events you actually want a run for. Trigger format from xAI's Grok Bot docs. Full reference: docs/grok-bot.md.

How these are counted

    The @-mention reply bot, live

    Mention an agent on X and it can reply through the same tools Grok uses. Aggregate activity only, read live from the bot's own ledger.

    Reliability

    A probe connects to each server every five minutes, runs the MCP handshake and calls one real tool. These are its results.

    Never hangs a task

    A render can take minutes on a cold GPU. Every call answers within 40 seconds, with the model or a job id, and Grok collects it with check_job. Nothing times out half-done.

    Your own quota

    Every Grok user reaches us from xAI's cloud. Limits follow your MCP session, not xAI's IP address, so one busy user never spends yours.

    A body, not just a file

    create_agent_persona turns a rigged model into a named body that lip-syncs and emotes. Grok can bring the same body back in any later task.

    Check the catalog first

    FAQ

    Do I need a three.ws account?

    Searching the catalog of ready-made assets needs no account. Making or rigging a model needs a free three.ws account, so every model has an owner who can publish or delete it.

    With ?auth=oauth on the URL, Grok asks you to approve three.ws sign-in once. Clients that cannot do OAuth take a connector key from API keys instead. Signing in also lets Grok work with your three.ws agents.

    What does it cost?

    Nothing. The studio is free with a three.ws account, inside limits that follow your MCP session. When a limit is reached, the tool answers with which limit it was and when it resets.

    Your Grok usage stays on your own Grok plan or xAI API key; three.ws never bills it. No tool on this connector can pay for anything.

    What data does three.ws receive?

    Only the arguments of each tool call Grok makes, such as a prompt, a photo URL or a model id. The rest of your conversation stays with Grok.

    Models you make are saved to your account and stay unlisted until you publish them. The usage counts behind the Live numbers store a salted one-way hash of the client, never your account id, key or IP address. Details in the privacy policy.

    Which URL should I use?

    https://three.ws/api/mcp-grok is the server built for Grok: every call answers inside Grok's time limit, and the signed-in tools for your agents ride on the same URL. Use it in every Grok surface.

    The plugins for Grok Build and Cursor connect the studio server, https://three.ws/api/mcp-studio, which serves the same 3D tools to any MCP client.

    Is three.ws made by xAI?

    No. three.ws is an independent company building on the Grok API. three.ws is a member of xAI's Grok for Startups program.
