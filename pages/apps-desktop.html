Apps/Desktop app

Desktop app Windows and Linux

Your agents, and a companion, on your desktop.

A console for your agents with a 3D character that strolls along the bottom of your screen and walks over to tell you what is worth interrupting you for. Not a notification center: a small person who knows which messages matter.

Prefer the browser? The web desktop needs no install.

What you get

  • A companion that delivers in person

    It walks to the middle of your screen, waves, and says the line aloud in the sender’s voice, wearing the sender’s avatar. It never eats a click meant for your editor.

  • You set the bar

    Threshold, quiet hours and per-contact priority live on three.ws/companion. The app is a body, not a second set of rules.

  • Agent console

    Sign in, chat with your agents, follow runs and see pending approvals from one window or the tray panel.

  • Local agents

    Run agents on your machine with keys in the OS keychain. Paper strategies work offline. Local runtime guide.

  • Native spend approvals

    Every spend shows an OS-level approval with the payload hash before anything signs.

  • Tray and start at login

    Pause from the tray, start at login, and open the menu bar panel for your agent, wallet balance and a one-line ask box.

Run it from source

Needs Node.js 20 or later and Git. This is also the way to run it on a Mac until the macOS build ships.

git clone --depth 1 https://github.com/nirholas/three.ws
cd three.ws/apps/desktop
npm install && npm start

Get started

  1. Install itDownload the installer for your system above, or run it from source.
  2. Sign inSign in from the window that opens, or run npx @three-ws/companion login --token cmp_… with a token from three.ws/companion.
  3. Set your barChoose which messages and events are worth a visit from your companion.

Requirements

Windows
Windows 10 or 11, 64-bit
macOS
Not yet released. Run it from source.
Linux
64-bit Ubuntu 18.04+, Debian 10+, Fedora 39+ or another distribution with glibc 2.28+

Builds are unsigned for now, so Windows SmartScreen or your Linux file manager may ask you to confirm before the first launch. Verify a download against the SHA-256 in the table. Read the menu bar panel guide too.
