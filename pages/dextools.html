three.ws x DEXTools

DEXTools charts run inside every coin chart on three.ws. In the other direction, any DEXTools pair can be rendered as a live 3D scene keyed by the pair address already in its URL, and any project can embed a card that sends its community to its DEXTools pair page, where every visit counts toward Social Boost. This page has all of it in one place, with live numbers.

How the two connect

Each integration below is live in production. None of them needs a key, an account or a data agreement.

For developers

			

				
Pair to token
GET /api/coin/pair?address=<pair> resolves a DEXTools pair to the token it trades.

				
Counted DEXTools link
GET /api/coin/dextools?address=<mint>&from=<surface> lands on the top pair page and counts the visit.

				
Traffic totals
GET /api/coin/dextools-stats?days=30[&token=] returns visits by day, by surface and by coin.
