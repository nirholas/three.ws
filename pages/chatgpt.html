Set it up in three steps

Works on ChatGPT Plus, Pro, Business, Enterprise and Edu, in ChatGPT on the web. Once added, the app follows your account to every chat.

  1. Turn on developer mode

    Open ChatGPT settings, then go to SettingsApps & ConnectorsAdvanced settings and switch on Developer mode. On newer accounts the tab is called just Apps.

    On a Business, Enterprise or Edu workspace, an admin may need to allow developer mode for members first.

  2. Create the three.ws app

    Back on Apps & Connectors, select Create and fill in the form exactly like this:

    Name three.ws 3D Studio
    Description Turn text or a photo into an interactive 3D model or a rigged avatar, right in the chat.
    MCP server URL https://three.ws/api/mcp-chatgpt
    Authentication No authentication

    Tick the box that says you trust the app, then select Create. ChatGPT connects and lists the tools it found.

  3. Ask for something in 3D

    Start a new chat, open the + menu, choose Developer mode, tick three.ws 3D Studio, and ask. Or just name it: "Use three.ws 3D Studio to make a 3D model of a red vintage scooter." The model lands inline in a viewer you can spin and download.

Questions and fixes

I do not see Developer mode or a Create button

Developer mode is on ChatGPT Plus, Pro, Business, Enterprise and Edu, in ChatGPT on the web (chatgpt.com). It is not in the mobile apps' settings, but once you create the app on the web it works in your chats everywhere. On a workspace plan, ask your admin to allow developer mode.

ChatGPT says it could not connect to the server

Check that the URL is exactly https://three.ws/api/mcp-chatgpt with no trailing space, and that Authentication is set to No authentication. The status line at the top of this page tests the same server from your browser. If it is green, delete the app and create it again.

ChatGPT answered without using three.ws

Tick the app under +, Developer mode in that chat, or name it in your message ("Use three.ws 3D Studio to..."). ChatGPT only calls an app that is turned on for the conversation.

A model is taking a while

A cold GPU can take a few minutes for a detailed model. ChatGPT gets an answer within 40 seconds either way: the finished model, or a job id it collects with check_job. Say "check on my model" and it picks it up.

Does it cost anything? Do I need an account?

No and no. Every tool is free and operator-funded, with a fair hourly limit per ChatGPT user. Models are yours to download and use. Sign up at three.ws only if you want a library, agents and higher limits.

Can I use it in other AI apps?

Yes. The same studio connects to Claude, Grok, Cursor, VS Code and any MCP client. See Connect other AI clients and the 3D Studio MCP docs.
