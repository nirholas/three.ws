TRELLIS.2 is built and released by Microsoft Research under the MIT license: a 4-billion-parameter flow transformer over O-Voxel structured latents that turns one image into a textured, PBR-ready 3D asset. This lab runs the released weights unmodified.

How we run it

GPU
NVIDIA L4 (24 GB), one per instance
Platform
Google Cloud Run with GPU, region us-central1, scales 0 to 2 instances
Container
CUDA 12.4 on Ubuntu 22.04, Python 3.10, PyTorch with the O-Voxel and FlexGEMM extensions compiled in the image (workers/model-trellis2)
Pipeline
Trellis2ImageTo3DPipeline, 512 / 1024 / 1536 cascades, background removal, GLB export with baked PBR textures
