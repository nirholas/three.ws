Import skills from any registry

Any public GitHub repository of SKILL.md files, or any registry manifest, works here. Each skill is pinned to the exact commit it was read at, its licence is checked, and it is scanned for hidden instructions and for requests to spend, sign or send messages. Nothing reaches your agent until you approve it.
