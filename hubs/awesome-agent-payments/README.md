# Awesome Agent Payments

A curated, community-fed directory of the protocols, facilitators, SDKs, wallets, and marketplaces that let software agents pay for things and get paid.

Agents are starting to do real work: calling APIs, buying data, renting compute, hiring other agents, checking out at merchants. All of that needs money to move without a human clicking "confirm" on every request. A new stack is forming to make it work: HTTP 402 payment protocols such as **x402** and **MPP**, authorization and mandate standards such as **AP2**, merchant checkout protocols such as **ACP** and **UCP**, card-network agent credentials, and wallets with spend controls. This list maps that stack in one place, **Solana first**, because Solana's sub-second finality and sub-cent fees suit machine-sized payments.

**Who it is for**

- Developers adding a paywall to an API or MCP server, or giving an agent a wallet.
- Teams comparing facilitators, protocols, and custody options.
- Researchers and builders who want a machine-readable index of the ecosystem.

Every entry lives in [`data/entries.json`](data/entries.json), so the list is easy to query, diff, and reuse. The tables below are generated from it.

**Add your project:** open a pull request that adds one JSON object. See [CONTRIBUTING.md](CONTRIBUTING.md) for the exact format, or use the [add-project issue template](.github/ISSUE_TEMPLATE/add-project.md) if you would rather have a maintainer do it.
