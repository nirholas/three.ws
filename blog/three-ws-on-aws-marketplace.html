three.ws on AWS: AWS Partner, Marketplace Listing in Preparation

three.ws is an AWS Partner. The AWS Marketplace listing is in preparation and is not yet published. This post describes what is built and what is still to come. It does not describe a live Marketplace product, because there is none yet.

  • AWS Partner page: three.ws/aws
  • Open source: github.com/nirholas/three.ws
  • Project site: three.ws

Where things stand

  • AWS Partner Network. three.ws is enrolled in the APN Software Path.
  • Marketplace listing. Not yet created in the AWS Marketplace Management Portal. When it publishes, the subscription will be free and usage will be paid per call in USDC over x402, so AWS Marketplace will not meter or bill that usage.
  • Backend integration. The SaaS fulfillment, account-linking and subscription-lifecycle endpoints are implemented in the open-source repository and wait for a published listing to receive traffic.

What you get today

three.ws is an open-source stack for autonomous 3D AI agents that run natively in the browser. Every <agent-3d> tag deploys an agent with:

  • A Solana NFT identity. Each agent can be minted as a Metaplex Core asset, transferable, owned, and verifiable on-chain.
  • An ERC-8004 identity. The cross-chain agent-identity standard, with IdentityRegistry, ReputationRegistry, and ValidationRegistry contracts deployable on any EVM chain.
  • A browser-native 3D body. Rendered in WebGL via three.js, with no plugins and no native install.
  • A multi-model brain. The agent runtime supports Claude among other models, with gestures, emotion blending, memory and skills.
  • Native x402 / HTTP 402 payments. Agents pay for what they consume and earn for what they offer, settling in USDC on Base, BSC, and Solana.

The technical integration

The Marketplace SaaS contract is implemented in open source:

  • POST /api/aws-marketplace/register: the fulfillment endpoint that exchanges the x-amzn-marketplace-token for a customer identifier through ResolveCustomer.
  • POST /api/aws-marketplace/subscription: the SNS notification webhook, with signature verification and subscription lifecycle handling.
  • POST /api/aws-marketplace/link: the account-linking endpoint that attaches a subscription to an authenticated three.ws account.

The code is at github.com/nirholas/three.ws/tree/main/api/aws-marketplace.
