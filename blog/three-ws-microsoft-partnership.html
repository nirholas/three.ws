three.ws Partners with Microsoft and Goes Live on Microsoft Marketplace

three.ws and Microsoft have announced a partnership, and three.ws is now live on Microsoft Marketplace. Open-source 3D AI agents (a body, a voice, memory, skills, a wallet and an on-chain identity) can now be found and procured through the same marketplace Microsoft customers already use to buy cloud software, AI apps and agents.

View three.ws on Microsoft Marketplace →

What Microsoft Marketplace changes for buyers

Microsoft Marketplace is the single storefront where Azure Marketplace and Microsoft AppSource now live together. For an enterprise team, finding three.ws there means the evaluation starts inside a procurement flow they already trust, with the publisher profile, offers and contact path in one place instead of a new vendor relationship built from scratch.

Nothing about the product forks for this channel. The same platform that runs at three.ws is what a Microsoft customer gets:

  • 3D creation. Text, photo or sketch to a rigged, animated 3D model, and an avatar from a prompt or a selfie, on our own GPU fleet.
  • An agent runtime with a body. Voice, emotion, memory and skills, with a talk mode that lip-syncs the avatar to what it says.
  • One tag to ship it. The <agent-3d> web component drops a finished agent into any page, intranet or app.
  • Tools for every assistant. MCP servers, SDKs and plugins expose generation, rigging and animation to any AI client.
  • An agent economy on Solana. x402 pay-per-call, on-chain identity and reputation, with Solana as the home chain.

Already built on Microsoft technology

The partnership formalises a relationship the codebase already had. Parts of the open-source stack Microsoft publishes run in production at three.ws today:

  • TRELLIS.2, from Microsoft Research, is the default image-to-3D lane on our self-hosted GPU fleet. See how the Forge works.
  • ONNX Runtime Web runs models directly in the visitor's browser.
  • Adaptive Cards render the Glance agent cards for home screens and chat.
  • TypeScript types every SDK we publish, and Playwright drives our browser tests.

Part of a multi-cloud distribution strategy

Microsoft joins the programmes and channels already listed on three.ws/partners: OpenAI, IBM, AWS, Google Cloud, Alibaba Cloud, NVIDIA, Quicknode and HackerNoon. The goal stays the same across every one of them: meet builders and enterprises where they already work, and keep the platform open source under Apache 2.0 so nobody is locked in.

Solana remains the home chain. Agent wallets, x402 settlement and the $THREE coin all live there, and a marketplace listing is a new way in, not a new center of gravity.
