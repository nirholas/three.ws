## Why this matters

Lane E to G identity, distribution, launch. Solana agent tooling moved in 2026 from SDK kits to the open Agent Skills format installed with a single command. three.ws already builds a skills pack for its own agents; making that pack installable by any agent runtime puts our 3D, avatar and wallet skills in front of every user of those runtimes.
