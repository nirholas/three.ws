# plan-specs/

The raw reviewer specs from the 2026-11-03 planning sweep (see [../plan-00-INDEX.md](../plan-00-INDEX.md)). Each file carries `slug`, `title`, `tier`, `score`, `area` and `sources` frontmatter plus the measured current state that the reviewer recorded.

These are source material, not work orders. The paste-ready order built from a spec lives in [prompts/finish/](../../) as `NNN-plan-<slug>.md`. A spec with no matching order there was either finished (the order deleted itself in its closing commit and logged a line in [../plan-PROGRESS.md](../plan-PROGRESS.md)) or folded into another order.

They lived at the repository root until 2026-11-04 and were moved here to keep the root limited to config and entry-point files.
