apps/desktop (Companion) is a transparent always-on-top mascot that delivers notifications; apps/forge-desktop (Forge) is a local 3D toolchain. Neither runs agents. Users who want keys that never leave their machine, and strategies that run while the cloud is unreachable, need a local runtime.

Extend apps/desktop into an agent runtime on top of packages/agent-runtime: run agents, strategies, orders and automations locally, keep signing keys in the OS keychain (Electron safeStorage), and optionally sync configuration and receipts with the cloud account. A tray menu shows each agent's status with pause, kill and approvals, and native notifications carry approval requests using the same payload-hash confirmation as the web flow, so an approval cannot differ from what was shown. The mascot becomes the agent's face: it reacts to state (working, waiting for approval, error).

Security: context isolation on, an IPC allowlist, no key material in logs or crash reports, signed auto-update. Build installers with electron-builder for macOS, Windows and Linux and produce the Linux artifact in this session; signing certificates missing are an owner action to list. README with install steps and a runnable example, STRUCTURE.md row, and a smoke test that starts the runtime headless and runs a paper-mode strategy.
