# Contributing

This starter optimizes for the shortest honest path from opening a repository to seeing a live
3D agent. Changes should preserve that focus.

1. Fork the repository and create a focused branch.
2. Run `npm ci` and `npm test`.
3. Exercise the page at 320px, 768px, and a desktop width.
4. Open a pull request describing the learner outcome that improved.

Do not add account requirements, private credentials, generated secrets, fake API responses,
or a framework build step. Examples must call public, documented three.ws surfaces.
