Tool access

Choose which tool groups your agents and MCP connectors can use on this account.

Read and write tools are on by default. They look things up or change account state that a follow-up call can undo.

Financial tools are off by default. They move funds or cannot be undone. Setting a group to On turns on every tool in it, financial ones included. Off hides the whole group. Default keeps read and write on and financial off.
