# Scenario inputs

Files a story scenario hands to the page with an `upload` step. They live in the repository so every
machine that reviews a post runs the scenario with the same bytes, and the proof records each file's
SHA-256: swap a file and the proof is void until the story is filmed again.

Every file here must be free to publish, because it appears in a public reel.
