## Format (verified live 2026-11-04)

Kilo's `CONTRIBUTING.md` ("Contributing MCP Servers") requires `id`, `name`, `description`, `author`, `url`,
`category` (one of `business`, `data`, `development`, `observability`, `productivity`, `search`,
`web-automation`), and `content` (one or more install configs). A remote server is a `content` entry whose JSON
is `{"type": "streamable-http", "url": ...}`, the same shape as the live `mcps/context7/MCP.yaml`.
`mcps/marketplace.yaml` is regenerated by the repo's `generate-marketplace.yml` workflow after merge, so the
PR adds only the one source file.
