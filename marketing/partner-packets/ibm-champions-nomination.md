## Evidence gaps, stated plainly

- **Granite is not configured on the hosted platform today.** `GET https://three.ws/api/ibm/galaxy`
  returned `{"available":false,"reason":"watsonx_not_configured"}` on 2026-09-16, and
  `POST /api/watsonx/embed` answered from `nvidia/nemotron-3-embed-1b`, not Granite. The Cloud Run
  service carries no `WATSONX_*` variables, and commit `2effca36a` (2026-07-29) records that the
  credentials "exist nowhere". The pipeline row in
  [docs/partners/opportunities.md](../../docs/partners/opportunities.md) that says "run Granite in
  production" is therefore stale. Restoring watsonx credentials would make the product-feedback
  criterion true again; until then, leave it out.
- **No IBM certifications are recorded.** IBM's 2025 announcement asks for "clear evidence of
  technical expertise (such as certifications)". None exist in the repo.
- **Speaker name.** IBM's event page names the "three.ws team" and lists nich as contact; it does not
  name an individual presenter. Describe the role as "contact and presenter" only if the nominee
  presented.
- **Tenure.** All IBM-property activity falls inside June to September 2026. That is a short record for
  a program that recognizes sustained advocacy; the monthly group cadence (one post per week allowed,
  last catalogued post 2026-08-08) is the cheapest way to lengthen it before the window closes.
