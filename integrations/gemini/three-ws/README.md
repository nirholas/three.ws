# three.ws extension for Gemini CLI

Free text-to-3D for [Gemini CLI](https://github.com/google-gemini/gemini-cli).
Ask for "a 3D model of a brass telescope" or "a rigged astronaut I can animate" and
Gemini returns a real, downloadable GLB plus a browser viewer link. There is no
payment. Making or rigging a model needs a free three.ws account, so every model has an
owner who can publish or delete it (new models stay unlisted until you publish them).

The extension has no local code. It connects Gemini CLI to the hosted three.ws studio
MCP server and adds three slash commands, four skills and a short context file that
teach Gemini when to use which tool.

## Install

```bash
gemini extensions install https://github.com/nirholas/three-ws-gemini-extension
```

Then start Gemini CLI and sign in once:

```text
/mcp auth three-ws
```

That opens the free three.ws sign-in in your browser (it can create an account with an
email code, Google or Microsoft). Gemini CLI stores the token in
`~/.gemini/mcp-oauth-tokens.json` and refreshes it. The consent screen asks for your
profile and your 3D models only (`profile`, `avatars:read`, `avatars:write`,
`offline_access`). Searching the catalog works before you sign in.

Then ask: `Make a 3D model of a small wooden three-legged stool.`

**Update:** `gemini extensions update three-ws`. **Remove:**
`gemini extensions uninstall three-ws`.

**With an API key instead of OAuth** (headless machines, CI): create a key at
<https://three.ws/dashboard/api-keys>, export it as `THREE_WS_API_KEY`, and add this to
`~/.gemini/settings.json`. A server in `settings.json` overrides the extension's server
of the same name, so the commands and skills keep working:

```json
{
  "mcpServers": {
    "three-ws": {
      "url": "https://three.ws/api/mcp-studio",
      "type": "http",
      "headers": { "Authorization": "Bearer ${THREE_WS_API_KEY}" }
    }
  }
}
```

## What the agent gets

The server's tool list comes from `https://three.ws/api/mcp-studio` at run time.
These are the 21 tools it lists today:

| Tool | What it does |
| --- | --- |
| `forge_free` | Text to textured GLB on the free lane |
| `mesh_forge` | Art-directed text or reference-image to GLB |
| `text_to_avatar` | Text or reference image to a textured avatar GLB |
| `forge_avatar` | Text to rigged, animation-ready avatar in one step |
| `rig_mesh` | Adds a humanoid skeleton and skin weights to a GLB you already have |
| `refine_model` | Edits a model you generated by describing the change ("make it metallic") |
| `check_job`, `get_job` | Collects a generation that returned `pending` |
| `look_at_model` | Renders a GLB from several angles and returns the frames as images, so the agent can see what it made |
| `search_catalog`, `get_catalog_item`, `get_item_source` | Searches thousands of ready-made CC0 props, rigged characters and motion clips, and returns embed code |
| `search_docs` | Searches the three.ws documentation |
| `create_agent_persona`, `get_agent_persona`, `persona_say` | Turns a generated GLB into a named, reusable talking 3D persona |
| `pano_capture_start`, `pano_capture_status`, `pano_capture_list` | Turns 360 camera footage at a public URL into a walkable Gaussian splat scene (PLY, SPZ, flythrough video, viewer link) |
| `pano_scene_create`, `pano_scene_status` | Turns one 360 photo into a textured depth-shell GLB you can stand inside |

Every generation links a run receipt: a signed, stage-by-stage record of what was
expected, what was observed and whether it passed, so a weak draft is named as one
instead of being presented as finished.

## Commands

| Command | What it does |
| --- | --- |
| `/make-3d <description>` | Catalog check, `forge_free`, a render check, then the GLB, viewer link, receipt and embed code |
| `/rig <GLB URL>` | Checks the model is a humanoid, rigs it with `rig_mesh`, and prints the rigged GLB and pose-studio link |
| `/embed <GLB URL>` | Paste-ready HTML: an animated `<agent-3d>` for a character or a `<model-viewer>` for anything else |

If another extension already owns one of these names, Gemini CLI renames ours to
`/three-ws.make-3d` (and so on).

## Context and skills

`GEMINI.md` is loaded into every session while the extension is enabled. It tells
Gemini to search the free CC0 catalog before generating, to render a model with
`look_at_model` before calling it done, and how to sign in. It is about 40 lines.

| Skill | Use it for |
| --- | --- |
| `generate-3d-model` | A static object, prop or creature from text |
| `create-3d-avatar` | A posable, rigged humanoid character |
| `rig-a-model` | Rigging a GLB the user already has |
| `find-3d-assets` | Checking the free CC0 catalog before generating anything |

The skills are byte-identical copies of the three.ws skill pack in
[`.agents/skills/`](../../../.agents/skills/). `tests/gemini-extension.test.js` in the
three.ws repository fails if a copy drifts from its source.

## Disclosures

Read this before you install.

- **Network calls.** Every tool call is an HTTPS request to `three.ws`, a third-party
  service run by the three.ws team. Prompts, reference image URLs, and GLB URLs you
  pass in are sent there. `look_at_model` and `rig_mesh` fetch the model URL you give
  them from three.ws's servers.
- **Models belong to your account.** Each model is filed under your three.ws account
  and kept out of the public gallery until you publish it. The GLB is stored on the
  three.ws CDN at an unguessable URL that anyone with the link can open, and it stays
  until you delete it from the model page or ask for removal. Do not put private or
  confidential details in a prompt.
- **No training, no sale.** three.ws does not use your prompts, tool inputs or
  generated files to train AI models, and does not sell them.
- **What reaches your model provider.** Tool results (URLs, metadata, and the rendered
  frames from `look_at_model`) enter the session context, and so reach Google.
- **Credentials.** The extension stores no keys or tokens. The server URL ends in
  `?auth=oauth`, so the first connect answers with a standard MCP OAuth challenge and
  Gemini CLI runs the three.ws sign-in when you type `/mcp auth three-ws`.
- **No local processes.** No hooks, no shell commands, no background processes, no
  telemetry. The extension is configuration plus Markdown and TOML.
- **No payments.** Nothing on the studio server costs money or charges you, and no
  tool on it can move money.
- **Rate limits.** The free studio caps generations per account per hour. When a call
  is refused, the response says when the quota resets.
- **Tool list is server-side.** The tool list is served by three.ws at run time, so
  installing a fixed version of this extension does not pin it.
