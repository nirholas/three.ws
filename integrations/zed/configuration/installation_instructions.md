The three.ws context server needs no account or key. Text-to-3D, asset search and avatar inspection tools run on the free tier of https://three.ws.

Optional settings:

- `base_url`: point the tools at a self-hosted three.ws API instead of https://three.ws.
- `payment_address`: a Solana USDC address that receives payment if you operate this server for other people.

Ask the Agent Panel for "a 3D model of a wooden chair" and it will call the Forge tools and return a GLB link.
